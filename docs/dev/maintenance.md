# 维护规则

## 阅读顺序

先读项目概述与架构；修改配置同步 `_conf_schema.json`、README 和配置文档；修改流程或门禁同步测试文档及 agent 入口。

## 模块边界

- `main.py` 只做注册、生命周期和薄编排。
- 目录、身份、回执、偏好、委托和执行逻辑放在对应 service/infrastructure 模块。
- SQLite 路径只能来自 `StarTools.get_data_dir()`；禁止创建 `<plugin>/data`。
- 自定义目录 runtime 权威源是 SQLite；JSON 只作为一次性迁移源。
- 不恢复图片菜单、模板、字体、JPEG 缓存或浏览器/T2I 链路。

## 必测行为

- SQLite schema/事务/迁移备份/幂等/回滚；
- 插件生命周期同步与 custom 保留；
- UID、@、引用、别名、实时/观察身份和隐私；
- 原请求者权限、三种委托策略、回执状态和重复抑制；
- 偏好 80/20、历史脱敏与清除；
- 目录 CRUD、策略字段、WebUI 分页与 Skill 发现；
- 通用处理器跳过黑名单、自定义外部路由和递归阻止。

修改行为/API/配置/结构/测试时必须同步文档。失败应显露真实原因，不吞异常或伪造成功。新增超时、条数、截断、重试或降级必须有产品/平台依据并记录影响。
